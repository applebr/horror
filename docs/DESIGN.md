# 가위 (GAWI) — 기획서

> 자각몽 / 가위눌림을 소재로 한 2D 픽셀 공포 게임.
> FAITH 같은 아타리풍 저해상도 그래픽, 최소한의 색, 갑작스러운 소음, 단순한 픽셀로 표현하는 고어.

---

## 1. 한 줄 요약

엄마가 야간 근무를 나간 밤, 여덟 살 **하나**는 가위에 눌린다.
꿈속의 404호에는 사람을 세상에서 **오려 내는** 존재, **가위**가 산다.
하나는 엄마에게 배운 **손가락 세기**로 꿈을 자각하고, 오려진 가족사진 조각을 되찾아야 한다.

## 2. 핵심 아이디어

| 요소 | 내용 |
|---|---|
| 말장난 | **가위**(가위눌림) = **가위**(자르는 도구). 괴물의 이름이자 무기. |
| 자각몽 | 실제 자각몽 기법을 게임 시스템으로: **손가락 세기**(현실 확인), **다시 읽으면 바뀌는 글씨**, **거짓 깨어남**. |
| 고어 | 픽셀 몇 개로 표현하는 피, 잘린 손가락, 여섯 번째 손가락이 살을 찢고 자라나는 장면, 사진을 붙인 얼굴. |
| 공포 | 정적과 기다림, 사운드 큐, 서브리미널 플래시, 쫓기는 무력감, "뭔가 바뀌어 있는" 공간. |
| 반전 | 마지막 손가락 세기의 결과는 여섯이 아니라 **다섯**. 꿈이 아니다. |

## 3. 제작 범위 (이번 빌드 = "1장: 404호" 완결 데모)

**플레이 타임 15~25분, 처음부터 엔딩까지 한 번에 플레이 가능한 수직 슬라이스.**

### 포함 (이번에 만든다)
- 경고 화면, 타이틀, 설정(음량 / 전체화면 / CRT 효과 / 번쩍임 줄이기 / 글자 속도), 일시정지, 이어하기(자동 저장)
- 프롤로그(현실의 집) → 가위눌림 컷신 → 꿈속 404호 → 3개의 악몽(욕실·부엌·엄마 방) → 사진 맞추기 → 계단 추격 → 보스(가위의 방) → 엔딩 → 크레딧
- 시스템: 이동/조사, **손전등**(배터리), **손가락 세기**(자각 게이지), 자각 시에만 보이는 **절취선 통로**, 다시 읽으면 바뀌는 쪽지, 공포(심박) 게이지, 사망 → 마지막 수면등에서 재시작
- 적 4종: 가위(추적 AI + 보스), 손가락 무리(떼로 기어 옴), 엄마인 척하는 것(칼질 리듬 잠입), 얼굴 없는 아이들(빛을 비추면 멈춤)
- 절차적 컷신(코드로 그리는 "로토스코프풍" 애니메이션): 가위눌림 시점 컷, 손가락 클로즈업(여섯 번째 손가락), 사망 연출 4종, 엄마 얼굴, TV, 가족사진, 보스 최후, 꿈 자르기, 엔딩
- 사운드 전부 코드로 합성: 드론 앰비언스, 오르골 자장가(창작 멜로디), 추격 음악, 효과음 30여 종, **한글 음소 기반 속삭임/악마 목소리 합성**

### 제외 (다음 장 이후)
- 2장 이후 스토리(지워진 아이가 된 하나), 다국어(영어), 키 재설정 UI, 업적, 다중 세이브 슬롯

## 4. 이야기

**1998년 4월 4일, 밤 11시 44분. 어느 아파트 404호.**

1. **프롤로그 (현실)** — 엄마는 야간 근무를 나가며 "가위 눌리면 손가락을 세어 봐. 꿈에서는 손가락 개수가 이상하대."라고 알려 준다. 집 안을 둘러볼 수 있다. 가족사진 오른쪽이 이상하게 비어 있고, 그림일기의 가족 그림에는 사람이 셋이다.
2. **가위눌림** — 4시 44분. 몸이 움직이지 않는다. 방문이 열리고, 천장에 머리가 닿는 마른 형체가 커다란 가위를 들고 들어온다. *싹둑.*
3. **꿈속 404호** — 같은 집인데 복도가 길고, 시계는 4:44에 멈춰 있다. 손가락을 세면 **여섯 개**. 살을 찢고 자라난 손가락. 꿈이다. 벽에 피로 쓴 글씨가 보인다: *꼭꼭 숨어라.*
4. **가족사진 조각 3개**
   - **욕실**: 핏물 가득한 욕조. 자각 상태에서만 보이는 마개 줄을 당기면, 바닥에는 수십 개의 손가락. 그리고 그것들이 기어 나온다.
   - **부엌**: 등을 돌린 채 칼질하는 "엄마". 칼질 소리가 날 때만 움직일 수 있다. 도마 위에는 손가락. 얼굴에는 엄마 사진이 테이프로 붙어 있다.
   - **엄마 방**: 끝없이 반복되는 복도, 자각해야 보이는 절취선. 얼굴이 오려진 아이들이 숨바꼭질 노래를 부른다.
5. **사진** — 엄마, 하나, 그리고 **남자 모양으로 오려진 구멍**. "...아빠. 아빠가 있었어." TV가 켜진다. "다음은... 너야."
6. **계단** — 4층, 4층, 4층. 끝나지 않는 계단을 가위가 쫓아온다.
7. **가위의 방** — 오려진 사람들이 매달린 방. 자각한 채로 손전등을 비춰 가위를 쓰러뜨린다. 가위의 마지막 말: "가위는... 누군가를 꼭 잘라야 해." 하나는 가위를 들어 **꿈을 자른다**.
8. **엔딩** — 아침. 부엌의 엄마. "...얘, 너 누구니?" 방에서 아빠의 목소리. 하나는 손가락을 센다. 하나, 둘, 셋, 넷, 다섯. **다섯.** 꿈이 아니다. 가족사진에는 이제, 아이 모양의 구멍이 나 있다.

## 5. 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Z / Enter / Space | 조사, 대화 넘기기, 결정 |
| X (누르고 있기) | 손전등 |
| C | 손가락 세기 (현실 확인 → 꿈이면 자각) |
| Esc | 일시정지 / 취소 |
| F11 | 전체화면 전환 |

게임패드(레거시 입력 사용 시): 왼쪽 스틱 이동, A 결정, B 취소, X 손전등, Y 손가락 세기, Start 일시정지.

## 6. 시스템 상세

- **자각 게이지**: 꿈속에서 손가락을 세면(약 2초간 멈춤, 무방비) 가득 찬다. 시간이 지나면 줄어든다. 자각 상태일 때만 절취선 통로 통과, 숨은 글씨 보기, 손전등으로 가위 밀어내기가 가능하다. 대신 손가락을 셀 때마다 손이 더 끔찍해지고, 가위가 그 "생각"을 듣고 다가온다.
- **손전등**: 누르는 동안 켜짐. 배터리가 닳고, 끄면 충전. 손가락 무리는 빛에 타 죽고, 얼굴 없는 아이들은 빛 안에서 멈춘다. 가위는 **자각 상태일 때만** 빛에 밀린다.
- **공포 게이지**: 손가락 무리에게 닿으면 심장이 빨라지고 화면이 붉어진다. 가득 차면 사망. 가위/엄마/얼굴 없는 아이들에게 잡히면 즉사.
- **쪽지**: 꿈속의 글씨는 다시 읽으면 바뀐다(실제 자각몽 현상). 자각 상태에서 읽으면 "진짜" 내용이 보인다.
- **수면등**: 체크포인트. 닿으면 자동 저장. 사망하면 "다시 잠들었다." 후 마지막 수면등에서 재시작.

## 7. 아트 디렉션

- 내부 해상도 **320×240**, 월드는 **160×120**(2배 확대)으로 그려 아타리풍의 큰 픽셀. 글자/UI/컷신은 320×240.
- 32색 고정 팔레트, 장면마다 3~5색만 사용. 꿈속은 차가운 남색, 현실은 노란 전등빛, 자각 시 붉은 기운.
- 조명: 플레이어 주변의 작은 빛 + 손전등 원뿔, 4×4 베이어 디더링으로 어둠 단계 표현.
- 화면 효과: 흔들림, 빨간 플래시, 화면에 튀는 피와 흘러내림, 노이즈, 1~2프레임 서브리미널 컷, 스캔라인(옵션).
- 컷신은 12fps로 끊어 그려 손으로 그린 듯한 움직임.

## 8. 기술 구조

- **Unity 2021.3 ~ Unity 6** 호환. 씬/프리팹 의존 없이 `RuntimeInitializeOnLoadMethod`로 어떤 씬에서든 자동 부팅.
- 게임 로직과 렌더러는 **UnityEngine에 의존하지 않는 순수 C#**(`Assets/Scripts/Engine`, `Assets/Scripts/Game`). 8비트 인덱스 컬러 프레임버퍼에 직접 그린 뒤, Unity 층(`Assets/Scripts/Unity`)이 텍스처로 올리고 소리를 재생한다.
- 덕분에 Unity 없이도 `Tools/Harness`(.NET 콘솔)로 게임을 돌려 스크린샷을 찍고 자동 플레이 테스트를 할 수 있다.
- 모든 스프라이트는 코드 안의 아스키 아트, 컷신은 절차적 드로잉, 사운드는 실시간 합성. 외부 에셋은 한글 비트맵 폰트(갈무리, OFL)뿐.
